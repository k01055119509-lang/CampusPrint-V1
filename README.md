# 校园打印 1.4.0

学生选择 PDF/JPG/PNG 后自动上传并准备 A4 黑白预览与报价，实际检查预览、选择接收方式并下单。经营者核实到账后“确认收款并接单”，实际交付后“确认送达”。单面每张 0.50 元，实际双面每张 0.90 元，双面奇数尾张 0.50 元；配送费 0；整单内容页数含份数为 1–99 页。每个文件、每份独立起纸，仅配送本栋宿舍。

本机学生入口 `http://127.0.0.1:4328/`（`/user/` 同样可用）；经营后台 `http://127.0.0.1:4328/admin/`。公网访问需经营者提供服务器和 HTTPS 域名。

需要在其他Windows电脑解压使用时，选择`dist/CampusPrint-V1.4.0-Windows-x64-Portable-20261016-r2.zip`。该便携版内置Node.js和运行依赖，先双击首次设置再启动；详见[Windows便携版使用说明](docs/Windows便携版使用说明.md)。下方npm安装步骤用于源码版。

## 1.4.0 页面与流程

本版新增仅在学生首页底部展示的文字公告。订单所有者自动看到可直接复制的查询码；默认接收信息支持四种方式。未声明付款的用户直接取消会自动退回未核销原券，商户列表不再显示；曾声明过则由商户同意或不同意。已记录收款不能取消，退款后也不重新开放。商家原因取消可在一次确认中选择补偿，规则固定为9折、无门槛、封顶2元、发放起30天。后台核款退回只选择固定原因，删除新增记录财务异常功能。

经营首页单击营业按钮即可切换营业/休息；休息时暂停新上传、报价和下单，已有订单付款、查询、售后与履约继续。设置页仅保留系统维护、微信/支付宝收款码、文件清理与运行状态三个模块。管理员列表与“售后与反馈”分别提供独立页面。

学生选择可读取的收款渠道后自行转账，直接点击“我已付款”；参考信息和备注选填。声明成功后显示打印清单、履约进度、订单售后、订单查询码、服务说明与帮助五个模块。声明只表示等待商户核对，真实收款凭据仍由商户独立核实。接收方式每单主动必选，放门口不预选。订单售后保留五种类型，也可提交不关联订单的一般反馈；完整联系方式仅管理员可见。

广告本版默认关闭，两端不加载、没有入口或空白位置，原图片、顺序与实现保留，备份恢复继续包含经营图片。产品与契约版本为 1.4.0，计价规则仍为 1.1.0，已有订单金额及完成期限不重算。本轮实际软件验收见 [1.4.0 验收报告](docs/V1.4.0验收报告.md)，最终发行与本机运行结果另见源码交接目录。

## 安装和启动

Windows x64 已验证 Node 24.16.0 / npm 11.13.0。要求 Node >=24.16.0 <25、npm >=11。

```powershell
cd D:\CampusPrint-V1
npm ci
# 首次配置、.env 不存在时才复制样例。
Copy-Item -LiteralPath .env.example -Destination .env
npm run db:init
npm run admin:init
npm start
```

上述步骤用于新安装。管理员初始化交互输入用户名和隐藏密码，无默认密码；现有安装保留原账号和素材，升级不重复初始化或导入。学生默认免注册进入，浏览器访客凭证自创建起固定有效七天；原学生账号保留但暂时停用。干净发行包初始业务库和收款信息为空；未配置收款码时仍可下单，不能提交付款声明。当前管理页不提供楼栋及接单说明编辑。

当服务端显式开启 STUDENT_ACCOUNTS_ENABLED=true 时，原账号入口和安全功能恢复；默认 false。原注册只需用户名和密码。新密码须为 6–12 位，且同时包含英文字母和数字。用户登录后在“我的 → 账号安全”、管理员在后台顶部“账号安全”设置三个不同密保问题；改密须全部答对。操作说明和升级验证见 [注册与密保更新](docs/handoffs/注册与密保更新.md)。

前台运行时按 Ctrl+C 停止。Windows 子进程由本地脚本管理时，可运行 `node --env-file-if-exists=.env backend/server.js --stdin-control`，向其 stdin 写入一行 `stop` 受控关闭；仅为本地管道控制，不是 HTTP 接口。

新项目不迁移旧 Skill 应用用户、配置、数据库或文件。旧 `D:/SkillWorkbench-V1` 保留。发行目录白名单不含 .env、业务数据库、学生文件、测试身份和 node_modules。

## 保留、维护与验证

实际送达起连续七天后禁访问并清文件，保留订单、金额、收退款和文字售后。启动先清理，在线每五分钟内扫描。未完成订单不按送达规则删除；未下单上传按独立 24 小时规则处理。

受管理备份在 `var/managed-backups`，数据库含已提交事务；文档逐文件保存，期限不晚于原快照七天或订单更早期限。恢复仅写入全新空目录，HTTP 开放前校验最新台账和清单。最新证据缺失时仅恢复业务记录，学生文件保持不可读。网页无法删除用户或经营者已下载到设备的副本。

```powershell
# 离线维护需先停同库服务。
npm run files:cleanup
npm run --silent files:manifest
npm run backup:create
npm run backup:authority -- D:\CampusPrint-authority\一个全新空目录

# 以下仅源码目录使用，浏览器默认本机 Edge headless。
npm test
npm run test:api
npm run test:ui
npm run test:retention
npm run contract:check
npm run deploy:package
```

npm test 统一执行基础、文件、业务、学生接口、D 清理/恢复与干净部署、学生/后台浏览器和真实 OpenAPI 检查；均使用隔离测试存储。可通过 CP_TEST_BROWSER_PATH 指定本机 Chromium。源码测试需要 devDependencies；发行包仅保留运行与维护命令，安装用 `npm ci --omit=dev`。

## 1.1.0 访客、查询码和优惠券

下单后请通过订单详情保存独立查询码。换浏览器或清除数据后，凭码只恢复该单明细、付款信息和售后；不能预览/下载文件或直接取消。原浏览器所有者的文件能力仍受期限限制。学生端与后台使用独立 Cookie/CSRF，可在同一浏览器同时使用。

打印费按每文件、每份独立起纸计算。3 页双面一份 1.40 元，两份 2.80 元；10 页双面 4.50 元。旧订单保留原价，旧报价须重新准备并确认。

后台“优惠券”可生成折扣或满减券，每批 1–100 张，默认一张、七天，每张独立 25 字符码。一单一券，报价不占用，成功建单后占用，确认收款后核销。占用券到期/停用会独立暂停打印配送，记录收款不自动解锁，需逐单处理。退款不恢复已核销券。完整说明见 [学生使用说明](docs/学生使用说明.md)、[经营者使用说明](docs/经营者使用说明.md)及 [部署与维护说明](docs/部署与维护说明.md)。
