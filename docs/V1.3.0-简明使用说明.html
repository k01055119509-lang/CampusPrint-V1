打开学生端打开经营后台

以上入口用于运行服务的这台电脑；手机访问地址由经营者另行提供。本说明不会自行启动服务。

学生：选择后自动准备

  1. 选择 PDF、JPG 或 PNG，自动上传、解析并生成当前预览与报价。
  2. 按文件设置页码、份数和单双面，逐项打开生产预览检查，再勾选“确认预览与费用”。
  3. 填写房间，每单主动选择接收方式；送达前联系要填联系，其他要填说明，放门口不预选。
  4. 核对金额并下单。若结果不确定，按页面重试同一次请求。

付款：声明后等待核款

  1. 选择可用的微信或支付宝渠道，放大检查完整收款码和真实收款账户。
  2. 按金额自行转账，参考信息和备注选填，直接点“我已付款”。
  3. 订单进度显示打印清单、履约进度、售后、查询码、帮助五个模块。

付款声明不等于到账。商户独立核实后才确认收款；有暂停原因时继续等待处理。

经营者：两项主要操作

  1. 在真实渠道核实到账、金额、渠道和凭据，点“确认收款并接单”。真实交易凭据必须独立填写。
  2. 按清单下载生产 PDF，实际制作和配送。文件已选页且只含一份内容；每文件、每份独立起纸。
  3. 按用户所选接收方式真正交付后，点“确认送达”。

正常单无需逐次点击开始打印、打印完成、开始配送；异常、取消退款和重印仍在对应区域处理。

营业、反馈与设置

  • 首页单击切换营业状态；休息暂停新上传、报价和下单，已有业务继续。
  • 管理员与售后反馈各有独立页面。没有订单也可发一般反馈，完整选填联系仅管理员可见。
  • 设置只保留系统维护、两渠道收款码、文件清理与运行状态。
  • 广告本版下线，没有入口或空白位置，历史素材仍保留。

费用、查询码与文件期限

单面0.50元/张，实际双面0.90元/张，双面奇数尾张0.50元；配送费0。整单内容页数含份数为1–99页。3页双面一份1.40元，两份2.80元。

查询码请私下保存，换浏览器后只能恢复指定单的明细、付款与售后，不能预览或下载文件。一般反馈依赖提交时的浏览器凭证，清除或到期后不能凭订单码找回。

实际送达后连续七天到期禁访问并清理文件，未下单上传24小时；订单与文字售后保留。重印、退款、找回及备份不续期，设备上的下载副本由持有人清理。
