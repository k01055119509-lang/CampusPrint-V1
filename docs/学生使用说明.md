# 校园打印 1.4.0 学生使用说明

打开本机学生入口 `http://127.0.0.1:4328/`。默认无需注册，浏览器会建立独立访客身份。访客凭证从创建起固定有效七天；清除浏览器数据或换浏览器后，请使用保存的订单查询码找回相应订单。

## 下单和付款

1. 首页底部可查看商户发布的文字公告。商户休息时暂停新上传、报价和下单，已有订单仍可查询、付款核对和申请售后。
2. 选择 PDF、JPG 或 PNG，系统自动上传并准备预览和报价。每个文件分别选择页码、单双面和份数，检查每个文件的实际预览。整单含份数为 1–99 个内容页，仅提供 A4 黑白、本栋宿舍配送。
3. 如有优惠券，输入兑换码并查看新报价。一单一券，查看报价不消耗券，成功下单才占用。单面每张 0.50 元、实际双面每张 0.90 元、奇数页双面的尾张 0.50 元；每个文件、每份独立起纸，配送费为 0。
4. 填写房间并选择当面交付、送达前联系、放在房间门口或其他。送达前联系须填写联系方式，其他须补充说明。放门口需要主动选择。“我的”可保存默认接收方式；旧的文字说明不会自动转成放门口。
5. 按页面显示的可用收款渠道自行转账，再点击“我已付款”。这只是付款声明，商户核对后才会记录收款。核对退回时，页面显示未查到到账、金额不符或付款渠道不符，请核查后重新提交。

订单页面会自动显示可以直接复制的查询码。点击复制是手动操作，复制失败时可选择文本自行复制。请私下保存，勿公开。查询码有 32 个有效字符；优惠券兑换码有 25 个，两者用途不同。凭查询码只找回这一单的明细、付款信息和售后，不能读取文件或直接取消。

## 取消与补偿

没有记录收款的订单，取消分两种情况：

- 从未点击过“我已付款”：点击取消后直接结束，成功才返回订单列表，学生仍能查看记录，商户列表不再显示。尚未核销的原券自动解除占用，保留原码、规则和原到期时间。已到期或停用的券仍不可使用。
- 曾提交过付款声明：提交取消申请，等待商户同意或不同意。即使付款核对被退回，也仍属于此类。同意后结束订单并释放未核销原券；不同意则保留订单和原券占用。

**已经记录收款的订单不能取消，实际退款后也不会重新开放取消。** 付款、退款问题请通过订单售后联系经营者。

商家因自身原因取消未收款订单时，可以选择额外发放一张补偿券。规则固定为 9 折、无门槛、最高减免 2 元，自发放起连续 30 天有效。是否发放、规则、时间和使用状态可在订单中查看。原浏览器所有者可以查看和复制补偿码；凭订单查询码找回者只能查看规则和状态。补偿券是一张新的优惠券，沿用一单一券规则，不是退款。已核销券不因退款自动恢复。

## 履约、售后和文件

商户核实到账并接单后，订单进入“制作与配送中”；实际按所选方式交付后才显示完成。需要反馈时进入“售后与反馈”，可针对订单发起售后，也可提交一般意见。一般反馈依赖当前浏览器的访客凭证，没有额外找回码。

实际送达起连续七天后，文件不可再访问并清理，订单、金额及文字售后记录保留。重印、退款、优惠券和查询码都不延长期限。未下单上传另按 24 小时清理。已经下载到自己设备的副本请自行管理。
