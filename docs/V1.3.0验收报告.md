## 原失败与仍保留观察

首次 `npm test` 的API阶段208/209、退出1，隔离广告上传出现一次EBUSY/500。未改A后端，单次及十次观测复验均通过，完整209项重新运行通过；77操作契约也通过。没有得到该次具体文件操作栈，根因仍未定位，**不宣称修复**。原失败和问题回传保留，后续复现仍交A定位。

C跨端旧测试三次适配失败分别涉及 fieldset 有效禁用、付款声明成功后付款区正确收起，以及单击营业后未等待服务端确认。仅改C测试后完整商户组7/7通过，未修改A/B产品。相关主动中断图片场景产生 `ERR_STREAM_PREMATURE_CLOSE`，原日志保留，断言与页面异常检查通过。
