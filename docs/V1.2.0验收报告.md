# 校园打印 1.2.0 软件验收报告

日期：2026-10-15（Asia/Shanghai）。产品版本 1.2.0；计价规则版本仍为 1.1.0，单面 50 分、实双面 90 分、奇数尾张 50 分，按文件和份数独立起纸。

## 范围与实现

本轮接入新 A 实际接口，完成学生端和商户后台：订单详情售后入口去重；概览及设置页共用营业状态，休息停止新上传、报价和下单；微信和支付宝分别管理收款码，按 available 判断可用，旧单码按未归属 legacy 保留；付款声明与人工确认分别记录渠道和时间；五类反馈与选填电话/微信，完整联系内容仅管理员可读；最多五张共用广告、2–30 秒间隔、排序启停、替换删除，以及暂停、手动切换、减少动画和失败降级。

广告在首页介绍之后、下单页底部、订单列表及详情底部，随文档滚动。没有图不占位，一张静态，两张及以上轮播；离开路由释放计时器。收款图片完整显示、可放大，声明不会自动记款；换图、营业切换或反馈归类不会清除优惠券、财务或退款限制。

部署备份加入独立 advertisementRoot。快照复制广告图片并记录大小及 SHA-256；恢复前核对元数据与图片引用，拒绝损坏、丢图、链接、嵌套或非空目标。兼容七个迁移的 1.1.0 快照没有广告目录；恢复后正常升 104。学生七天到期清理及恢复不复活文件的规则继续成立，广告和收款图片不套用学生期限。

## 发行、迁移及使用边界

发行包白名单包含新增 merchant 后端模块、104 迁移、前端组件和广告备份恢复；不包含 assets-inbox、真实库、密码、收款码/广告素材、学生文件、测试代码与 node_modules。最终 ZIP、逐文件摘要、包内独立安装和七迁移旧库升级验证，以及本机受控启动结果，统一记录在包外本轮 `B-完成交接.md`，避免包内自包含摘要循环。

本机升级前核对 A 190 个旧源码副本、业务快照和独立 authority，不使用默认新代码 backup:create 备份旧库。旧账号、订单金额、券、工单、资金记录和文件期限按原事实保留。指定商户账号和两张真实收款码、三张真实广告由总控使用已授权凭证收尾，本轮测试不以合成图替代正式配置。

本报告的软件证据不代表真实手机、真实资金到账或退款、纸张试印、实体配送、域名/TLS 或公网部署通过。相关事项按《真实环境试用与纸张验收清单》现场验证。查询码、付款声明和软件状态均不会证明真实资金或纸张结果。
