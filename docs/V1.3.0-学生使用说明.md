# 校园打印 1.3.0｜学生使用说明

进入网页即可使用，默认免注册。浏览器访问凭证从建立起固定有效七天；清除浏览器数据或到期后，可以用保存的订单查询码找回指定订单。

## 下单

1. 在“打印下单”选择 PDF、JPG/JPEG、PNG，文件会自动上传、解析并准备生产预览和报价。Word、Excel、PPT、HEIC 等请先转为 PDF。遇到失败，按提示重试或主动移除失败文件；系统不会悄悄忽略它。
2. 每个文件选择页码、份数、单面或双面。页码可以填 `all`、`1-3,5`。来源文件可以超过99页，但本次整单内容页数乘入份数后须为1–99页。修改文件、打印参数或优惠码后会自动重新准备，并撤销原来的预览确认。
3. 逐文件打开生产预览，检查页序、方向、字体大小、比例和留白，再勾选唯一的“确认预览与费用”。自动准备不会替你查看或勾选。
4. 填写本栋房间号，每单主动选择“当面交付”“送达前联系”“放在房间门口”或“其他”。送达前联系须填联系方式，其他须填说明。放门口不默认选中，成功建单后下一单还须重新选择。
5. 核对金额并提交。若提示结果不确定，保持原输入并重试本次请求，不要另建一单。七天文件规则为普通说明，不再要求额外勾选或保存默认资料。

打印规格为 A4 黑白。单面每张0.50元，实际双面每张0.90元，双面奇数尾张0.50元；每个文件、每份独立起纸。本栋配送费为0。3页双面一份1.40元，两份2.80元；两个各1页的双面文件分别起纸，合计1.00元。

优惠码可按五位分组粘贴，支持大小写及空格/连字符。输入后自动重报价；一单一券，报价不占用，建单占用，确认实收后核销。券失效时保留原输入供你换码或移除；不自动改价建单，也不支持零元订单。

## 付款和订单进度

订单内选择真实可用的微信或支付宝收款码，放大核对完整图片和收款账户，按应付金额自行转账。参考信息和备注可不填，点击“我已付款”直接提交声明。只有系统明确确认本次声明成功，才显示待商户核款；声明不表示真实到账。

订单进度包含五个模块：打印清单、履约进度、订单售后、订单查询码、服务说明与帮助。商户实际核款接单后进入“制作与配送中”，按所选方式实际交付后才为“已完成”。暂停、取消和退款单独显示，付款声明与实收时间分别标注。被驳回时按提示补充或重新声明。

## 售后、反馈与找回

订单进度中的售后入口进入指定单的独立售后页。点击唯一的“发起售后/反馈”，可提交订单售后或一般反馈。订单售后保留打印质量、内容或份数不符、配送、付款退款、其他五类；一般反馈不需要订单。详细内容必填，电话或微信选填，完整联系方式只向管理员展示。

一般反馈依赖提交时的当前浏览器凭证，清除或失效后不能凭订单码找回，可选填联系方式便于经营者联系。文字回复和关闭工单不会自动退款。

订单查询码请私下保存。持码者只能恢复该单明细、付款与售后，无文件预览/下载、直接取消、完整码读取或原身份其他订单/一般反馈权限。遗失请联系管理员人工协助，不用房间号自动找回。

## 文件和营业状态

实际送达后连续七天到期禁访问并清理相关文件；未下单上传按独立24小时规则处理。退款、重印、找回、查看和备份都不延长期限。订单与文字售后继续保留。已下载到自己设备的副本由你自行清理。

休息或维护时暂停新上传、报价和下单，原订单查询、付款、售后和经营处理继续。广告本版下线，首页不显示近期订单，订单历史与查询入口保留。
