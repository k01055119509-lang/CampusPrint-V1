学生下单

  1. 选择 PDF、JPG 或 PNG，等待自动上传、预览与报价。每个文件分别选择页码、单双面和份数，实际检查预览。
  2. 填写房间，选择当面交付、送达前联系、放在房间门口或其他。送达前联系须填写联系方式，其他须补充说明；放门口需要主动选择。“我的”可保存默认接收方式。
  3. 有优惠券时输入兑换码并确认新报价，然后下单。一单一券，查看报价不占用，成功下单才占用。
  4. 按可用渠道自行转账，再点击“我已付款”，等待商户独立核对。核对退回时按原因检查并重新提交。
  5. 订单页自动显示查询码，点击即可复制，也可选择文本手动复制。请私下保存，换浏览器后凭码找回这一单。

单面每张 0.50 元，实际双面每张 0.90 元，奇数尾张 0.50 元；每个文件、每份独立起纸。整单含份数为 1–99 个内容页，配送费为 0。首页底部可查看商户公告。

取消和补偿

没有记录收款时，取消分两种：从未提交付款声明的订单直接取消，成功返回列表并自动释放未核销原券；曾提交过声明的订单则申请商户审核，退回过核款仍算曾声明。原券保留原码、规则和到期时间，过期或停用不会恢复可用。

已经记录收款不能取消。实际全额退款后也不会重新开放取消。付款或退款问题可通过订单售后联系经营者。

商家因自身原因取消未收款订单时，可选择发一张补偿券：9 折、无门槛、最高减免 2 元、发放起连续 30 天，每单最多一次。双方订单会保留发放记录；原浏览器所有者可查看补偿码，凭查询码找回者只看规则和状态。

经营处理

  1. 经营首页切换营业状态，并独立编辑、发布或停用首页公告。公告保存失败保留草稿；版本冲突时先核对并载入当前内容。
  2. 核对真实到账、金额、渠道和未重复的交易凭据，准确后“确认收款并接单”。金额不符请退回付款核对，选择未查到到账、金额不符或付款渠道不符，确认后回订单列表。
  3. 订单进入“制作与配送中”，按生产清单制作并按用户选择的方式交付，实际完成后“确认送达”。下载文件不代表已经完成制作。
  4. 用户取消申请只选择同意或不同意。同意包含核实未收款及释放原券的责任。商家主动取消选择原因和是否补偿，确认一次完成。
