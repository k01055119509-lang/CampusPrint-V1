# 校园打印 1.4.0｜Windows离线便携版

适用于Windows 10/11的x64电脑，建议4GB以上内存和至少2GB解压/运行空间，学生文件及备份另占空间。包内已有Node.js 24.16.0和运行依赖，不需要另外安装Node.js、npm、Office或联网下载依赖。此包不用于macOS、Linux或ARM64电脑；其他Windows版本需单独验证。

## 第一次使用

1. 将整个ZIP完整解压到一个可写文件夹，例如`D:\CampusPrint`。不要在压缩软件中直接双击脚本，也不要放在需要管理员写权限的Program Files目录。
2. 双击`01-首次设置.cmd`。按提示创建管理员用户名和密码，密码6–12位，须同时含英文字母和数字；输入时隐藏。没有预置管理员、默认密码或旧测试业务。
3. 双击`03-启动经营后台.cmd`，浏览器会打开本机后台。登录后上传你自己的微信、支付宝收款码，并确认营业状态和其他配置。
4. 双击`02-启动用户端.cmd`打开本机服务首页。两端可以在同一浏览器使用。
5. 使用结束时双击`04-停止服务.cmd`。关闭浏览器不会停止后台服务。

重复执行首次设置会保留已有管理员、密码和数据；不会清空数据库。第一次输入失败时重新执行即可。管理员账号需要自己保存，便携包不保存明文密码。

## 日常使用与数据

- 启动后服务在后台运行，无需保持命令窗口。默认学生端`http://127.0.0.1:4328/`，管理端`http://127.0.0.1:4328/admin/`。
- 数据在当前解压目录的`var`中；不同电脑的新解压副本分别使用独立数据库，订单不会自动同步。
- 本包是全新安装包，不含旧管理员、用户、订单、优惠券、公告、收款码或学生文件。需要的收款码由经营者自行上传。
- 学生默认免注册，广告默认停用。计价、人工核款、履约与售后规则沿用1.4.0。
- 文件仍按原规则清理：临时上传24小时；实际送达起七天后清理相关文件。运行时自动扫描，关闭服务期间请按维护说明安排期限清理。拷贝或恢复数据不会延长期限。
- 在投入实际经营后，应按部署维护说明备份业务和最新文件期限依据。不要把存有用户文件和凭据的整个运行目录公开发送给他人。

## 遇到问题

- 先双击`05-检查运行环境.cmd`。检查只读取配置并验证运行库，不创建管理员、订单或业务数据。
- 提示缺少文件时，重新完整解压原始ZIP。不要从别的Node.js版本复制文件覆盖runtime。
- 端口4328被其他程序占用时，先停止对应程序；如有需要，可在`.env`中将`PORT=4328`改成其他空闲端口，受控停止后重新启动。
- 同一端口上如果已运行其他副本，不能把该服务认作当前副本；请使用对应副本的停止入口后再启动本副本。
- 查看`var\desktop-logs\service.stderr.log`中的启动错误。Windows或单位安全策略限制本地程序/脚本时，按设备管理要求处理。
- 不要在运行时移动/删除文件夹，也不要直接用旧数据库覆盖当前数据库。旧ZIP和旧业务备份不是升级后事实的替代品。

## 访问范围

默认只在运行此包的电脑本机访问。解压便携版与公网部署是两件事；要让其他人的手机通过互联网访问，仍需部署服务器、域名和HTTPS，并完成适用的接入要求。
