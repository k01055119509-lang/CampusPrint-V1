# 校园打印 1.3.0｜经营者使用说明

经营后台为服务地址后的 `/admin/`，沿用已有管理员账号。升级不重建账号、不重置密码、不要求重新导入两渠道收款图片。干净新安装才执行管理员初始化；系统没有默认密码。

## 正常订单只需两项主要操作

1. 先在真实收款渠道核对实际到账、金额、渠道和交易号或凭据，再点“确认收款并接单”。金额和学生声明渠道供核对，真实凭据留空等待你独立填写；不能以学生自述或订单号代替外部凭据。同一交易凭据不能跨单重复记账。准确核款且没有限制时进入“制作与配送中”。
2. 下载生产 PDF，按清单实际制作和交付。每个生产 PDF 只含已选页面的一份内容，打印全部生产 PDF 页面，份数及单双面按清单设置；每个文件、每份独立起纸。无需依次点击开始打印、打印完成或开始配送。按用户所选方式真正交付后，点“确认送达”并确认实际交付，此时首次记录完成时间和七天期限。

用户主动选择门口时才可按该方式交付；联系不上不表示允许放门口。旧订单接收说明原文显示，没有历史接单时间就保持为空。下载不证明已经打印或送达，软件也不控制打印机驱动的所有行为。

## 异常、取消、退款和重印

订单的异常处理、取消退款和重印位于各自展开区。使用“原因类型＋补充说明”，其他原因须填写具体说明，普通原因可补充。历史文字和操作记录仍保留。

准确实收遇到券、财务、退款或制作配送暂停时，可以如实记款，但仍显示暂停。逐项解除原因，每次只清除选择的一项；认可原优惠不能解除财务异常，后续退款恢复决定也不会抹去先前要求停止履约的事实。打印失败恢复前还须核对已完成文件和副本，避免重复打印。

取消申请先暂停履约。已收款的取消须实际退款，或填写双方核实保留实收的结算依据；未付款状态不能证明现实未收到款。占用券取消释放需要明确人工未收款核查。已过期或停用的券不会因此恢复可用，已核销券退款也不恢复。

退款按申请、批准/拒绝、实际退回分别记录。批准不代表已经转账；实际退回须核实外部凭据，累计不得超过实收，并明确剩余履约恢复或停止。全额实退不能恢复履约。售后重印按原清单执行，不延长原文件期限，到期文件不能继续重印。

## 六个经营页面

- 经营首页：营业状态单击切换，进行中防连点；失败或结果不确定时先重读，核对结果后再操作。休息只暂停新上传、报价、下单，已有业务继续。收款、实际退款和净收款分开展示，净收款不是利润。
- 订单工作台：依照统一履约阶段筛选和查看打印、接收、核款、暂停及历史记录。
- 管理员：仅账号、搜索、分页，不提供学生访客列表或新增账号管理能力。
- 优惠券：原折扣/满减生成、专用码查看、筛选及停用保留，每批1–100张，默认1张、七天。
- 售后与反馈：订单售后和无订单一般反馈独立处理，可按类别、类型和状态筛选，查看提交者选填联系并回复。一般反馈没有关联订单链接，关闭工单不修改收退款或文件期限。
- 设置与维护：严格三个模块——系统维护、微信/支付宝收款码、文件清理与运行状态。维护与营业分开；两渠道图片支持预览、上传替换和清除。确认真实收款账户，别把未归属历史码猜成微信或支付宝。

广告本版无入口或主动加载，图片和历史配置保留在私有存储及备份中。不要为测试开启正式广告。

## 保留期限和安全

实际送达后七天禁访问并清理相关学生文件，未下单上传24小时；源、派生、预览及受管理备份均受相应期限限制。订单、金额和文字售后保留。启动会协调清理，运行中每五分钟内扫描；删除失败仍禁访问并重试。经营者下载到打印电脑的副本须自行清理。

查询码仅在专用面板显示，人工核实后私下提供。管理员顶部账号安全保留密保及改密能力。真实到账、打印机、纸张、手机和配送仍须经营者现场核对。
