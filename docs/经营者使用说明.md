# 校园打印 1.4.0 经营者使用说明

经营后台：`http://127.0.0.1:4328/admin/`。使用已有管理员账号登录；升级保留原账号及收款图片，不需要重新初始化。

## 营业与公告

经营首页直接切换营业或休息。休息暂停新上传、报价和下单，已有订单的付款核对、查询、售后及履约继续。

“首页公告”维护一条最多 1000 字的文字，支持换行。勾选发布并保存后，只出现在学生首页底部；取消发布并保存后隐藏，后台保留内容。保存失败会保留当前草稿。另一窗口已修改时，先核对当前版本再载入编辑，避免覆盖他人的结果。公告与系统维护、营业状态和收款设置分别保存。广告继续停用，不显示空位。

## 核款和交付

1. 在“订单工作台”打开订单，独立核对实际金额、渠道和真实交易凭据。学生“我已付款”只供参考，不代表钱已到账。
2. 金额准确时点击“确认收款并接单”，填写真实且未重复的凭据并确认核对。金额不符会拒绝记录收款，不再创建新的财务异常。请使用“退回付款核对”，选择未查到到账、金额不符或付款渠道不符之一并确认；无需补充说明，成功返回经营订单列表。
3. 正常接单后为“制作与配送中”。按确定的文件清单制作，每个文件、每份独立起纸；生产 PDF 只含一份已选内容，打印时按清单设置份数和单双面。下载文件不代表实际打印完成。
4. 按用户主动选择的方式交付后，点击“确认送达”。不得因联系不上而自行改为放门口。完成时间和七天文件期限从此时开始。

订单存在优惠券、退款、制作配送或旧财务暂停时，需要分别处理；记录准确收款或解除一项暂停不会清除其他限制。旧财务异常保留原记录和既有处理能力，后台已删除新增“记录财务异常”功能。

## 取消与补偿

**只处理未记录收款的取消。** 已收款订单不能发起或同意取消，实际全额退款后也不能重新取消。旧版遗留的已收款取消申请只允许不同意，从而结束取消暂停；实收和其他暂停继续保留。

- 用户从未提交付款声明就直接取消的订单，不进入商户订单、搜索、历史或相应统计。未核销原券自动解除占用，无需再核实退券；学生仍有记录。
- 用户曾声明付款后申请取消的订单，由商户选择同意或不同意，不需要重填理由。点击同意表示已经核实未收款，并在同一操作中释放未核销原券。核对被退回也算曾声明过，不能走直接取消。
- 商家主动取消时，选择“无法完成打印”或“经营方无法履约”，选择是否发补偿，然后确认一次即结束。补偿默认不发，无需再批准自己发起的取消。双方保留取消记录。

补偿方案固定：9 折、无门槛、最高减免 2 元、发放起连续 30 天，每单最多发一次。取消、原券释放和补偿一致完成，取消失败不能算发放成功。订单取消记录和操作记录会显示是否发放、规则、时间和券状态；完整码通过专用查看复制入口私下提供。优惠券页只读展示此预设，普通批量券仍按原规则生成，默认七天。

网络结果不明时保留原输入重试，界面沿用原请求；不要另开窗口反复执行同一取消或补偿。版本冲突时先核对刷新后的真实结果。

## 售后与维护

“管理员”“优惠券”“售后与反馈”分别独立。文字回复、关闭工单和批准退款不等于实际退款，实际收退款要有真实依据；软件不执行转账。已核销的优惠券不因退款恢复。

“设置与维护”仅有系统维护、微信/支付宝收款码、文件清理与运行状态三个模块。实际送达七天后清理学生文件，订单和文字记录保留；下载到经营设备的副本由经营者自行清理。需要部署、备份或升级时，使用本版部署与维护说明。
